Fire Fighting Robot

Objective: Design an autonomous robot capable of detecting and extinguishing fire without human intervention.

Arduino UNOFlame SensorMotor Driver L298NDC Water PumpServo Motor
⚙️ Working:

Flame sensors mounted at front detect fire in the robot's proximity. The microcontroller processes sensor data and steers the robot toward the fire source. Once within range, the servo-mounted water pump activates to extinguish the flame.

✨ Features:
  • Autonomous fire detection and navigation
  • 360° flame sensing capability
  • Servo-controlled water spray nozzle
  • Obstacle avoidance using IR sensors
🌐 Applications:

Industrial fire safety, unmanned firefighting in hazardous zones, research and demonstration.

Image Processing Based Fire Fighting System

Objective: Build an advanced fire detection system using computer vision to identify flames through a camera feed and deploy automated suppression.

Raspberry PiOpenCVPythonCamera ModuleServo + Pump
⚙️ Working:

A Raspberry Pi camera streams video to the OpenCV-powered Python script. The algorithm identifies fire-colored regions using HSV color thresholding. Upon detection, the system calculates the fire's position and controls servo motors to aim and activate the water pump.

✨ Features:
  • Real-time fire detection via video feed
  • Computer vision-based flame localization
  • Precision servo-controlled targeting
  • Remote monitoring via SSH / web stream
🌐 Applications:

Smart surveillance, advanced fire safety in server rooms, AI-driven safety systems.

Number Plate Detection System

Objective: Implement an automated vehicle number plate recognition system using image processing and OCR for real-time identification.

PythonOpenCVTesseract OCRRaspberry Pi / PCCamera
⚙️ Working:

The camera captures vehicle images. OpenCV applies edge detection, contour finding, and region-of-interest extraction to isolate the number plate. Tesseract OCR then converts the plate region into readable text, which is logged or compared against a database.

✨ Features:
  • Automatic plate region extraction
  • OCR-based character recognition
  • Real-time video processing
  • Database integration for access control
🌐 Applications:

Parking management, traffic monitoring, toll automation, vehicle entry control systems.

DIY Network Attached Storage (NAS) Server

Objective: Build a NAS server using an old laptop to enable secure local and remote file sharing across devices.

Linux MintSamba (SMB)Tailscale VPNNetworkingSystem Admin
⚙️ Working:

The old laptop runs Linux Mint and uses Samba to share a 62 GB USB drive and a 458 GB internal HDD over the network. Tailscale VPN provides a secure mesh network, allowing Android phones and Linux systems to access files seamlessly from anywhere with centralized authentication.

✨ Features:
  • Network-based file sharing using Samba (SMB)
  • Secure remote access through Tailscale VPN
  • Multi-storage management with centralized access
  • Automatic service startup and persistent availability
🌐 Applications:

Personal cloud storage, homelab networking, centralized device backups, low-cost NAS alternatives.

Low-Latency Media Streaming Server

Objective: Establish a low-latency local media streaming server using MediaMTX, OBS Studio, and VLC.

OBS StudioMediaMTXVLCStreamingNetworking
⚙️ Working:

OBS Studio encodes the media and pushes an RTMP stream to the MediaMTX server. MediaMTX acts as an ultra-low latency media router. VLC media player connects to the MediaMTX server to pull the RTSP stream and display it on the client side with minimal delay.

✨ Features:
  • Ultra-low latency video streaming
  • Support for multiple streaming protocols (RTSP, RTMP, WebRTC)
  • Lightweight media server configuration (MediaMTX)
  • Local network streaming without external cloud reliance
🌐 Applications:

IP camera monitoring, local network broadcasting, live event streaming, home surveillance.
